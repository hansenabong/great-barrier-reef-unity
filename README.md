# Great Barrier Reef Unity Project

## Branches
- `main` = stable / demo-ready version
- `develop` = integration / testing branch
- personal branches = individual work branches

## Workflow
- Do not push directly to `main`
- Do not push directly to `develop`
- Work only on your own branch
- Open Pull Request from personal branch to `develop`
- Only merge tested `develop` into `main`

## Merge Flow
personal branch -> develop -> main
